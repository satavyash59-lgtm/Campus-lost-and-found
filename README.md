# Campus Lost and Found

A simple web-based platform for students to report and find lost items within their college campus.

## Features

* View lost and found items
* Search for items
* Browse items by category
* Report a lost or found item
* View item details
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS

## Project Structure

```text
Campus-Lost-and-Found/
│
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Future Improvements

* User login and registration
* Database integration
* Add and remove items dynamically
* Image upload for lost items
* Search and filter functionality
* Backend integration
* Email or notification system

## Purpose

This project is developed as a college project to provide a simple solution for managing lost and found items on campus.
